# STRIKEPOINT 1.0.0 beta

## Northflank
1. Распакуй ZIP. Загрузи содержимое (не сам ZIP) в приватный GitHub-репозиторий. Для крупных файлов используй git с компьютера: веб-загрузка GitHub ограничена 25 MiB на файл. Максимальный файл assets/inferno.glb около 93 MiB, ниже лимита git 100 MiB.
2. В Northflank создай проект и Combined Service из репозитория, выбери Dockerfile в корне.
3. Создай PostgreSQL addon (если доступен на твоём тарифе) и подключи его строку подключения как секрет DATABASE_URL. Не публикуй секрет в GitHub. Без базы работает гостевой режим.
4. Открой публичный HTTP port 8080, включи HTTPS. Health endpoint /health. WebSocket endpoint /ws на том же домене.
5. После деплоя открой выданный HTTPS-домен. Для проверки открой две вкладки/устройства и зайди в один режим и карту. Консоль: connect домен, lobby код, status, disconnect.

Локально: Node.js 22, npm install, npm start; http://localhost:8080. PostgreSQL необязателен для гостевого теста.

## Ограничения beta
Онлайн — прототип: комнаты до 10/4 игроков, передача позиций, поворотов, HP, базовые попадания и возрождение. Нет серверной геометрии/проверки стен, полноценного античита, синхронизации гранат/C4, экономики, раундов, ботов и инвентаря. Онлайн не является полноценным соревновательным матчем. Локальная тренировка сохраняет старый игровой режим. Модели/звуки из предыдущей версии; перед публичной публикацией проверь лицензии на все ассеты. Three.js загружается с CDN как ранее. Старые SQLite аккаунты автоматически не переносятся. На HTTPS нужен WSS; обычный ws:// с HTTPS страницы браузер блокирует. Не открывай базу данных публично.
